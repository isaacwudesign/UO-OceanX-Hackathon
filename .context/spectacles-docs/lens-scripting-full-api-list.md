# Lens Scripting API — Full API List

The **Full API List** is the generated TypeDoc index for Lens Studio’s JavaScript/TypeScript scripting surface. It lists built-in types, modules, properties, and methods (for example `SceneObject`, `Transform`, `SupabaseModule`, `DeviceInfoSystem`, animation, physics, networking, and utilities like `vec3` / `mat4`).

**Official page:** [Full API List | Lens Scripting API](https://developers.snap.com/lens-studio/api/lens-scripting/documents/Full_API_List)

Use it when you need the authoritative spelling of APIs, parameters, and return types while writing Lens scripts in Lens Studio.
