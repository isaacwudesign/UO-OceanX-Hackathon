## What Snap Cloud is

[**Snap Cloud**](https://cloud.snap.com/) is an integrated backend platform powered by **Supabase**. It adds backend capabilities to Spectacles Lenses: with minimal setup you can use **databases**, **storage**, **edge functions**, and **realtime** connectivity. That supports seamless data sync, content storage, and trusted **server-side** logic.

Snap Cloud integrates with **Lens Studio** so you can create backend instances for your Lenses with minimal configuration, using the **Supabase Plugin**.

---

## Databases

Snap Cloud provides a **fully managed, scalable PostgreSQL** database for your Lenses. Lenses can query and update the database with simple API calls. Data stays secure, consistent, and available across devices, so you can build **persistent, context-aware** AR—for example tracking scavenger-hunt progress across sessions or sharing AR assets between users.

Further reading: [Databases | Snap for Developers](https://developers.snap.com/spectacles/about-spectacles-features/snap-cloud/databases)

---

## Edge functions

**Edge functions** run custom **server-side** TypeScript/JavaScript **close to users**, with very low latency. Typical uses include content generation, game logic, integrations with third-party systems, and media processing.

---

## Storage

**Snap Cloud Storage** lets you securely **upload, organize, and retrieve** files from a Lens—images, videos, 3D models, user-generated assets, and more. **Fine-grained permissions** control who can read or contribute. You can power AR with stored assets, let players upload and share content, or cache images for social challenges.

---

## Realtime

**Realtime** enables **instant, bidirectional** data sync for collaborative, dynamic AR. Subscribe to live updates from database tables and push changes to Lens clients in milliseconds. Use it to **synchronize state** across clients or to maintain live links to backend services.
